# Piyush Kumar — Portfolio

A responsive, single-page portfolio for Piyush Kumar. It is built with plain HTML, CSS, and JavaScript, so no install or build step is needed.

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension for automatic refresh while editing.

## Personalize

- Update project descriptions and add repository or live-demo links in `index.html` when those URLs are ready.
- Replace the circuit-board image URL in `index.html` with a personal project image or portrait.
- Adjust colors, spacing, and mobile layouts in `styles.css`.
- Contact details and education are in `index.html`.
